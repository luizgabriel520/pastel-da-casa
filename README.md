# Pastel da Casa (React)
- `src/data.js`: CONFIG (WhatsApp, Instagram, taxas por bairro, depoimentos, sabores e preços).
- `src/App.jsx`, `Hero.jsx`, `Cart.jsx`, `hooks.js`, `ui.jsx`: componentes. `src/mkgl.js`: shader do vapor. `src/site.css`: estilos.
- `img/`: fotos (provisórias, recortadas da referência). Troque por fotos reais mantendo os nomes.
- `npm install && npm run build` gera `dist/index.html` (React pré-renderizado, um único arquivo).

## Comandos
- `npm run dev`: servidor local em http://localhost:5173 com recarga automática.
- `npm run build`: gera `dist/index.html` final (um único arquivo, pronto para publicar).
